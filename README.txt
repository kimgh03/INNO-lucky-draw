사용자가 qr을 인식하면 사이트로 들어가짐. 사이트에는 https://www.instagram.com/innohostel?utm_source=ig_web_button_share_sheet&stkn=ZDNlZDc0MzIxNw== 인스타 팔로우하면 무료 쿠폰을 준다는 멘트와 함께 해당 인스타로 바로 들어갈 수 있는 UI가 필요함.
사이트는 그냥 하얀배경에 INNO Hostel이 상단에 적혀있게 센스것 눈치있게 만들어주면 될듯
그리고 사용자가 follow 하면 앱에서 무료 음료 쿠폰이 제공될건데
그 팔로우를 하면 lucky draw하는 chance가 생기고 그 버튼을 누르면 룰렛이 돌아가면서 당첨되는 거였으면 좋겠어.
종류는 draft beer 450ml, draft beer 270ml, melon sour, purple rain, jin tonic 이렇게 5개.
팔로우 안하면 사이트에 chance가 안생겼으면 좋겠는데 팔로우 했는지 확인이 될지 모르겠네.
만약 안되면 직원 확인 버튼을 생성해서 직원확인 Yes 누르면 chance가 생기게 해줘.
